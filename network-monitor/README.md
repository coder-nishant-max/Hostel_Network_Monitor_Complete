# Hostel Network Monitor

## Run on Windows
1. Open this folder (`network-monitor`) in VS Code.
2. Open Terminal > New Terminal.
3. Run `python -m pip install -r requirements.txt`
4. Run `python app.py`
5. Visit http://127.0.0.1:5000 in your browser.

Use only on a network you own or are authorized to monitor. Device results are based on this computer's ARP cache and may not list every connected device.
